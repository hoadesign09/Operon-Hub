### Việc cần làm tay trên Local / Staging / Production
1. Copy `.env.example` thành `.env` và điền thông tin MySQL Local (`DB_HOST=127.0.0.1`, `DB_USER`, `DB_PASSWORD`, `DB_NAME=operon_hub`).
2. Tạo database MySQL trống: `CREATE DATABASE IF NOT EXISTS operon_hub CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;`
3. Chạy `npm run db:migrate` (trên Local) và `npm run dev`, mở `http://localhost:3000` để xem màn hình trạng thái xanh `HEALTHY`.
4. Trên Staging/Production: **không** chạy `db:migrate` tự động (đã bị khóa an toàn); chạy SQL phần `-- UP` trong `database/migrations/20261123_000001_init_settings.sql` theo quy trình triển khai DB chuẩn.
