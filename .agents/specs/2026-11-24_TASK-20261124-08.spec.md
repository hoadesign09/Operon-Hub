# Task Spec: Phase 2 Batch 2 (`P2-TASK-06` → `P2-TASK-12`) — Full Project Management Suite

## 1. Functional Requirements (FR)
- **FR-06 (Agile Sprints & Burndown/Velocity):** CRUD Sprint (`PLANNED`, `ACTIVE`, `COMPLETED`, `CANCELLED`), assign/move Backlog ↔ Sprint, Start Sprint (1 active sprint per project guard), Complete Sprint in atomic transaction with carryover (`NEXT_SPRINT` or `BACKLOG`), Burndown ideal vs actual series + Velocity chart (6 recent sprints).
- **FR-07 (Milestones, Gantt CPM & Baseline):** CRUD Milestones with auto progress %, approval hook `PM_MILESTONE_SIGNOFF`, Capture Project/Task Baseline (`baseline_start_date`/`baseline_due_date`), Gantt API with Critical Path Method (CPM) + `autoShiftDependents` for `FS`/`SS`/`FF`/`SF`, interactive Gantt UI with zoom Day/Week/Month, baseline bars, critical path toggle & dependency indicators.
- **FR-08 (Time Tracking & Weekly Timesheet):** Server-side Live Timer Start/Stop (`started_at`, 12h warning), Manual Time Log, auto-rollup `tasks.actual_hours`, Weekly Timesheet grid (Mon–Sun) with `DRAFT` → `SUBMITTED` → `APPROVED`/`REJECTED` workflow, global `QuickTimerWidget` in Topbar + Drawer.
- **FR-09 (HRM-Integrated Workload Heatmap):** Read-only cross-module join combining open `tasks`, `project_members`, HRM `holidays`, and HRM `APPROVED` `leave_requests`; compute per-employee capacity, allocated hours, and utilization % (`< 60%`, `60–100%`, `> 100%`) with quick task reassignment.
- **FR-10 (Budget/Cost & RAID 5×5 Register):** CRUD `project_budget_items` (`DECIMAL(18,2)`), auto-sync `LABOR` cost from `APPROVED` time logs, approval hook `PM_BUDGET_CHANGE`, CRUD `project_risks` (`RISK`/`ISSUE`, `probability 1..5 × impact 1..5 = severity_score`), 5×5 heatmap matrix, and 1-click Convert Issue → Action Task (`linked_task_id`).
- **FR-11 (Templates, Recurring Tasks & Automation Rules):** Save existing project as `project_templates` (columns + tasks + relative `T+N` offsets), create project from template with date shifting, CRUD `task_recurrence_rules` + manual/scheduled `run-due` runner, CRUD `project_automation_rules` with loop depth = 1 guard (`TASK_MOVED_COLUMN`, `ALL_SUBTASKS_DONE`, `TASK_ASSIGNED`, `TASK_OVERDUE`).
- **FR-12 (Executive Portfolio Dashboard & Excel/PDF Exports):** Portfolio KPI summary (projects by status & RAG, on-time delivery rate, budget burn, hours logged, high-severity risks), Excel exports (`exceljs` — Tasks, Timesheets, Portfolio), PDF A4 Vietnamese Project Status Report (`pdfmake`), full bilingual VI/EN UI, full regression suite + Excel Test Case sync.
